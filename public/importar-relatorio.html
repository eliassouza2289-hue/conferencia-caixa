🖨️ Como emitir os relatórios no Trier

Passe o mouse nos botões de imagem para ver onde marcar cada opção. No celular, toque no botão.

1. Fechamento de caixa

  1. Buscar "fechamento de caixa".
  2. Selecionar por número de caixa.
  3. Informar o número do caixa.
  4. Marcar as opções da tela, exceto "Filtrar Movimento pela Data do Lançamento" e "Desconsiderar frete".
  5. Selecionar saída HTML.
Busca Opções HTML

2. Relação de vendas Tele entrega

  1. Buscar "relação de vendas".
  2. Marcar "Imprimir Formas de Pagamento".
  3. Marcar "Vendas Tele-Entrega".
  4. Selecionar saída HTML.
Busca Opções HTML

3. Relação de vendas Tipo Cartão

  1. Buscar "relação de vendas".
  2. Marcar "Imprimir Formas de Pagamento".
  3. Filtrar tipo cartão 10, 11, 13, 14, 15 e 17.
  4. Selecionar saída HTML.
Busca Tipos HTML

Depois de gerar os três arquivos em HTML, selecione todos juntos no campo "Relatórios HTML".

Selecionar relatório

Selecione os HTMLs juntos. O sistema identifica fechamento, cartões e tele-entrega automaticamente.

Aguardando HTML
Pode selecionar os 3 arquivos de uma vez. O fechamento é obrigatório; cartões e tele são usados para a pré-checagem.
